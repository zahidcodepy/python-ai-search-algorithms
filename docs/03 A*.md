## Overview

**A\* Search** is an informed search algorithm that finds the shortest path between a start and goal node by combining the actual cost from the start node with a heuristic estimate of the cost to the goal. It is one of the most widely used pathfinding algorithms in AI, robotics, and game development due to its balance of optimality and efficiency.

A* evaluates nodes using the function:

```text
f(n) = g(n) + h(n)
```

- **g(n)** — the actual cost from the start node to node `n`
- **h(n)** — the heuristic estimated cost from node `n` to the goal
- **f(n)** — the estimated total cost of the cheapest path through `n`

---

## How It Works

A* maintains a priority queue (min-heap) of nodes to explore, ordered by their `f(n)` value. At each step, it expands the node with the lowest `f(n)`, updates the costs of its neighbors, and continues until the goal is reached. Provided the heuristic is **admissible** (never overestimates the true cost), A* is guaranteed to find the optimal path.

---

## Algorithm Steps

1. Add the start node to the priority queue with `f(start) = h(start)`.
2. While the priority queue is not empty:
   - Remove the node with the lowest `f(n)` value.
   - If it is the goal, reconstruct and return the path.
   - For each neighbor, calculate a tentative `g(n)` score.
   - If this path to the neighbor is better than any previously known, update its cost and add it to the priority queue.
3. Repeat until the goal is found or the queue is empty (no path exists).

---

## Pseudocode

```text
A*(graph, start, goal, h):
    create priority queue open_set
    add start to open_set with priority f(start) = h(start)

    g_score[start] = 0

    while open_set is not empty:
        current = node in open_set with lowest f value

        if current == goal:
            return reconstruct_path(current)

        remove current from open_set

        for neighbor in graph[current]:
            tentative_g = g_score[current] + cost(current, neighbor)

            if tentative_g < g_score.get(neighbor, infinity):
                g_score[neighbor] = tentative_g
                f = tentative_g + h(neighbor)
                add neighbor to open_set with priority f

    return failure
```

## Example

**Grid/graph with edge weights and a heuristic (e.g., Manhattan or Euclidean distance to goal):**

```text
A --1-- B --2-- D
|               |
2               1
|               |
C --1-- - - - - E   (goal)
```

A* expands nodes in order of lowest `f(n) = g(n) + h(n)`, avoiding exploration of clearly suboptimal branches that both BFS and DFS would still visit — resulting in fewer node expansions for the same optimal result.

---

## Complexity Analysis

| Metric | Complexity |
|--------|:----------:|
| Time Complexity | O(E) in the worst case (heavily dependent on heuristic quality) |
| Space Complexity | O(V) |

With a strong, well-informed heuristic, A* explores significantly fewer nodes than uninformed methods like BFS or DFS. With a poor or zero heuristic, A* degrades toward the behavior of Uniform Cost Search / Dijkstra's algorithm.

## Use Cases

- Pathfinding in video games and robotics navigation
- Route planning in maps and GPS systems
- Puzzle solving (e.g., 8-puzzle, 15-puzzle)
- Network routing optimization

---

## Advantages & Limitations

**Advantages**
- Guarantees the optimal path when the heuristic is admissible
- Generally more efficient than uninformed search methods
- Widely applicable across weighted graph problems

**Limitations**
- Performance depends heavily on the quality of the heuristic function
- Can consume significant memory for large search spaces, since it keeps all generated nodes in memory
